## Трудности

Проще всего прочитать файл целиком в строку. Но тогда в памяти висят сразу две копии: эта строка и уже разобранная таблица. Я читаю кусками, в один буфер фиксированного размера. Если строка оборвалась на границе куска, её конец остаётся в том же массиве, следующий кусок дописывается следом. Отдельный буфер под строку не нужен, файл может быть какой угодно длины.

## Куда это можно развить

Файл я уже читаю потоком, но после разбора все ячейки всё равно лежат в массиве. Можно таблицу в память вообще не класть: один раз пройти файл, узнать ширину, высоту и какой там перевод строки, а дальше по координате прыгать `Seek` и читать один байт. Таблица прямоугольная, адрес ячейки считается из этих трёх чисел, список строк не нужен. Имеет смысл, когда сетка уже не влезает в память.
